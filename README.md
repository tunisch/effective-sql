# 📘 Effective SQL – Fundamentals (English & Turkish Documentation)

## 🇬🇧 English

> 📌 Overview

This repository is a structured learning space designed to help you understand SQL fundamentals through clear explanations and practical examples.

The goal is not only to write SQL queries, but to **think in SQL** — understanding how filtering, sorting, pattern matching, and logical operations work in real databases.

> 🎯 Purpose

This repo aims to:
- Teach SQL fundamentals step by step
- Provide real examples using PostgreSQL
- Explain each SQL concept with simple, focused markdown files
- Build a strong foundation for backend development, data analysis, and technical interviews
- Encourage clean, readable, and efficient query writing


> 📂 Repository Structure:

## 📂 Repository Structure (English)

| File Name                           | Description                                      |
|-------------------------------------|--------------------------------------------------|
| `select.md`                         | Basics of the SELECT statement with examples     |
| `where-and-comparison-operators.md` | WHERE clause + comparison operators               |
| `where-and-logical-operators.md`    | Logical operators: AND, OR, NOT                  |
| `like-and-ilike.md`                 | Pattern matching using LIKE and ILIKE            |
| `between-and-in.md`                 | BETWEEN and IN operators                         |
| `distinct-and-count.md`             | DISTINCT and COUNT usage                         |
| `README.md`                         | Project overview                                 |
| `LICENSE`                           | License information                              |

Each markdown file focuses on a specific SQL topic:

All examples are written with clarity and real-world use cases in mind.

> 🧠 Learning Approach

This repository follows a **learn-by-doing** philosophy:
- Understand the concept
- See a real example
- Apply it to a practical scenario
- Build intuition for SQL logic

> 🛠 Technologies

- PostgreSQL
- Standard SQL syntax
- Markdown documentation

> 🚀 Who Is This For?

- SQL beginners
- Backend developers
- Data analysts
- Students preparing for technical interviews
- Anyone who wants to strengthen SQL fundamentals

> 📌 Notes / Notlar
This repository will continue to grow with new examples and explanations.
